# Préférences pour ce projet

- Procéder par défaut sans demander confirmation : commits, `git push`, relancer
  `generer_tout.py` (régénération complète du site), édition/patch de masse sur
  les fichiers générés. Ne pas attendre d'approbation avant ces actions.
- Reste valable : éviter les actions destructrices non demandées (`rm -rf`,
  `git reset --hard`, etc.) sans le dire clairement dans le résumé de fin de tour.
